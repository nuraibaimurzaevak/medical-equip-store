 Medical Equipment Store (Интернет-магазин медоборудования)
Простой и чистый интернет-магазин медицинского оборудования(MongoDB, Express, React, Node.js). Основные возможности: просмотр каталога, добавление товаров в корзину и оформление заказа.

[Клиентская часть (client/)] | [Серверная часть (server/)]

✨ Основной функционал
🔐 Аутентификация: Регистрация, вход, выход, защищённые маршруты.

🎭 Авторизация по ролям: Интерфейс и логика сервера меняются в зависимости от роли (например, кнопка "Админ-панель" видна только Admin).

📦 Базовый магазин: Каталог, корзина, оформление заказа.

⚙️ Управление: CRUD для товаров (Manager/Admin) и пользователей (только Admin).

🛠️ Стек технологий
Часть	Технологии
Фронтенд	React (Create React App), CSS
Бэкенд	Node.js, Express.js
База данных	MongoDB (через Mongoose)
Прочее	REST API, Git

🚀 Быстрый старт
Клонируйте репозиторий:

bash
git clone https://github.com/baimurzaeva/medical-equip-store.git
cd medical-equip-store
Запустите сервер:

bash
cd server
npm install
npm start    # Сервер на http://localhost:5000
Запустите клиент:

bash
cd ../client
npm install
npm start    # Приложение на http://localhost:3000
